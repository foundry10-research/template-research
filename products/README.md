# Products

The things this project publishes: a peer-reviewed manuscript, a white paper,
a brief report, a preprint. A project may produce one of these or all four.

They are written in Google Docs or Word, not in this repository. Git is bad at
tracking prose written by several people at once, and nobody should have to
change how they write to use version control. This folder records **where the
writing lives** and holds the final versions once there are any.

## The one rule: every number comes from the full report

[`../reports/full_report.md`](../reports/full_report.md) is the record of the
study. Every statistic, sample size, and effect in a product must appear
there. When you are drafting, copy numbers from the rendered full report, not
from the R console and not from memory.

If a product needs a number the full report does not contain, the fix is to
add it to the report: put the calculation in `code/02_analyze.R`, pull it into
`reports/full_report.qmd`, re-render. Never compute a number on the side for
one document. The most common reproducibility failure in a finished paper is a
number typed into a table three revisions ago that no longer matches what the
code produces.

Before a product goes out, run `/check-report` and record the date in the
table above. It confirms the full report meets the reporting standard and,
if you paste in the product's text, checks that each number in it appears in
the report.

## What is worth keeping in this folder

- The final accepted or published version as a PDF, once there is one
- Supplementary materials that are generated by code (as a `.qmd` that reads
  from `results/`, following the same rules as `reports/`)
- Reviewer-requested analyses, so the connection between a revision and the
  code that produced it survives

## Figures for products

Draw the figure in `reports/full_report.qmd` and add a `ggsave()` line in the
same chunk writing a high-resolution copy to `output/figures/`. Insert that
file into the document. One place for the figure code; see
[`../reports/README.md`](../reports/README.md).
