# Manuscript

Most drafting happens in Google Docs or Word, not in this repository, and that is fine — Git is genuinely bad at tracking prose written by several people at once, and nobody should be asked to change how they write in order to use version control.

Use this folder to **record where the writing lives** and to hold anything that belongs alongside the code.

## What is worth keeping in the repository

- The final accepted version as a PDF, once there is one
- Supplementary analyses that are generated by code
- Reviewer-requested analyses, so the connection between a revision and the code that produced it survives
- A `.qmd` or `.Rmd` source file, if you write reports in R

## Numbers in the manuscript should come from `output/`

The most common reproducibility failure in a finished paper is a number typed into a table by hand three revisions ago that no longer matches what the code produces. When you update an analysis, regenerate the tables and figures rather than editing them in place.
